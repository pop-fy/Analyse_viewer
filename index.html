ตัวดูผลวิเคราะห์ตามผู้รับผิดชอบ

วิธีใช้

  1. กด “เลือก folder ของคุณ” แล้วเลือก folder ที่เป็นชื่อคุณ (เช่น พี่แจม) หรือเลือก แบ่งงาน ทั้งอัน
  2. เลือกหน่วยงานที่ต้องการ จากนั้นสลับแท็บ วิเคราะห์ / Raw / ไฟล์แนบ
  3. ในแท็บวิเคราะห์ กดเลข “กิจกรรม N” เพื่อเปิดข้อความต้นฉบับใต้จุดที่กด ข้อความที่ใช้เป็นหลักฐานจะถูกไฮไลต์ (กดซ้ำเพื่อปิด)

ไฟล์ไม่ได้ถูกส่งไปไหน หน้านี้อ่านจากเครื่องของคุณโดยตรง ไม่ต้องต่ออินเทอร์เน็ต
